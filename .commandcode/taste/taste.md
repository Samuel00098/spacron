- Prefers 2K resolution (2560×1440) for generated image assets to ensure sharpness on larger screens. Confidence: 0.8
- Prefers WebP format over PNG for image assets. Confidence: 0.8
- For UI backgrounds (e.g., behind frosted-glass overlays), strongly prefers calm, atmospheric, even-toned visuals with painterly softness over photographic sharpness — "fine art print" not "stock photo." - Values even luminance across visual compositions — no bright hot spots or deep shadow pockets; backgrounds should be functional UI support layers, not attention-grabbing focal points. Confidence: 0.7
- For dark mode visuals, prefers restrained compositions where most of the frame is near-black with sparse, dim elements and minimal light sources; avoids dramatic/bright elements competing with darkness. Confidence: 0.7
