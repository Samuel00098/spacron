A terminal-first workspace for developers.

Terminal, editor, live preview, and git — one native window, keyboard-driven, sub-second startup. No extensions, no accounts, no cloud.

➜ preview    localhost:5173 proxied

terminal

Full PTY shell sessions via xterm.js. Up to four split panes. Detects your shell automatically.

editor

CodeMirror 6 with highlighting for 15+ languages, Vim mode, minimap, and format on save.

preview

Local dev-server proxy with hot-reload injection and a built-in DOM inspector.

git

Diffs, staged and unstaged changes, and commits without leaving the window.

native

Tauri 2 and Rust. A small binary that starts in under a second, not an Electron app.
